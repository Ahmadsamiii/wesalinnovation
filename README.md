# وصال

منصة ذكاء اصطناعي عربية تساعد الأشخاص ذوي الإعاقة في السعودية على الوصول إلى معلومات
موثوقة عن حقوقهم والخدمات والتقنيات المساعدة المتاحة لهم.

---

## البنية

| الطبقة | الوصف |
|---|---|
| الواجهة | `index.html` — تطبيق صفحة واحدة، بلا خطوة بناء وبلا اعتماديات. الأنماط والسكربت مضمّنان في الملف نفسه. |
| الخلفية | `api/` — ست نقاط PHP تتكلّم JSON وتتشارك `db.php`. |
| قاعدة البيانات | MySQL 5.7+ عبر PDO — ستة جداول معرّفة في `schema.sql`. |
| النموذج | Gemini أساسي، مع سلسلة نماذج بديلة ← OpenAI ← قاعدة معرفة محلية داخل الواجهة. |

لا يوجد `npm` ولا `composer` ولا خطوة تجميع: ما في المستودع هو ما يُرفع للخادم.

### الملفات

```
index.html              الواجهة كاملة (٢٬٧٧٧ سطراً)
.htaccess               ترويسات الأمان والضغط والتخزين المؤقت لجذر الموقع
schema.sql              مخطط قاعدة البيانات — المرجع الوحيد للبنية
api/
  config.example.php    نموذج الإعدادات — انسخه إلى config.php
  config.php            الإعدادات الفعلية (مستثنى من Git، محجوب عن الويب)
  db.php                الاتصال والجلسة والدوال المشتركة وحدود الاستخدام
  auth.php              التسجيل والدخول والملف الشخصي وتذاكر الدعم والصورة الرمزية
  chat.php              المحادثة الذكية وحساب الرصيد
  admin.php             لوحة المشرف: المستخدمون والرسائل والتذاكر والدعوات
  contact.php           نموذج «تواصل معنا»
  diag.php              أداة تشخيص للمشرف — يُفضّل عدم رفعها للإنتاج
  .htaccess             يحجب config.php و db.php عن الوصول المباشر
assets/  fonts/  partners/   الشعارات والخطوط وشعارات الشركاء
uploads/                الصور المرفوعة (يُنشأ تلقائياً، مستثنى من Git)
```

## التشغيل

### المتطلبات

- PHP **8.0** فأحدث، مع `pdo_mysql` و `curl` و `mbstring`
- MySQL 5.7 فأحدث (أو MariaDB 10.3+)
- Apache مع `mod_rewrite` و `mod_headers` — أو خادم مكافئ

### الخطوات

**١. أنشئ قاعدة البيانات وحمّل المخطط**

```bash
mysql -u USER -p -e "CREATE DATABASE wesal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -u USER -p wesal < schema.sql
```

**٢. اضبط الإعدادات**

```bash
cp api/config.example.php api/config.php
```

ثم افتح `api/config.php` واملأ بيانات قاعدة البيانات ومفتاح Gemini على الأقل.
كل ثابت موثّق داخل الملف.

**٣. ارفع الملفات إلى جذر الموقع**

ارفع محتويات المستودع إلى `public_html` (أو ما يعادله). تأكّد أن `.htaccess`
وصل فعلاً — بعض عملاء FTP يخفون الملفات التي تبدأ بنقطة.

**٤. أنشئ حساب المشرف**

افتح الموقع وسجّل حساباً جديداً. **الحساب الأول في قاعدة بيانات فارغة يصبح
مشرفاً عاماً تلقائياً** — سجّله بنفسك قبل فتح الموقع للناس.

**٥. تحقّق**

افتح `‎/api/diag.php` وأنت مسجّل بحساب المشرف. تعرض الصفحة حالة الاتصال
بقاعدة البيانات، وحالة مفتاح النموذج، وسلامة ملفات الشعار.

> بعد التأكد من التشغيل، احذف `api/diag.php` من الخادم أو قيّده بعنوان IP —
> فهو يكشف جزءاً من مفتاح النموذج ورد المزوّد الخام لمن يملك حساب مشرف.

## ملاحظات تشغيلية

### الإعدادات المتزامنة بين الطرفين

ثلاث قيم معرّفة في مكانين ويجب أن تتطابق، وإلا اختلف ما يراه المستخدم عمّا
يطبّقه الخادم:

| القيمة | في `api/config.php` | في `index.html` |
|---|---|---|
| حصة الزائر | `GUEST_LIMIT` | `GUEST_LIMIT` |
| رصيد المستخدم | `USER_TOKENS` | `USER_TOKENS` |
| دورة التجديد | `RENEW_HOURS` (ساعات) | `RENEW_MS` (ميلي ثانية) |

### حدود الاستخدام

الحدود مخزّنة في جدول `rate_limits` ومفتاحها عنوان IP — لا الجلسة — حتى لا
يمنح حذف الكوكي حصةً جديدة. ثلاث طبقات:

- **لكل دقيقة لكل IP** — تُضبط في الكود عند كل نداء `rateLimit()`
- **`CHAT_DAILY_IP_LIMIT`** — سقف يومي لنقاط الأسئلة من عنوان واحد
- **`CHAT_DAILY_TOTAL_LIMIT`** — سقف يومي للمنصة كلها، وهو قاطع الدائرة الذي
  يحمي فاتورة المزوّد. اضبطه على رقم يناسب ميزانيتك قبل أي إطلاق واسع.

الصفوف القديمة تُنظَّف تلقائياً بعد يومين.

### خلف Cloudflare

اضبط `TRUST_PROXY` على `true` فقط إذا كان الموقع خلف وكيل عكسي فعلاً. بدون
وكيل، تفعيله يسمح لأي زائر بانتحال عنوانه عبر ترويسة `X-Forwarded-For`
وتجاوز كل الحدود أعلاه.

### ترقية قاعدة بيانات قائمة

`ensureSchema()` في `api/db.php` تضيف الأعمدة والجداول الناقصة تلقائياً عند
أول طلب، لتبقى القواعد القديمة متوافقة. أي تعديل على البنية يجب أن يُضاف في
`schema.sql` **و** في `ensureSchema()` معاً.

## الأمان

- **لا ترفع `api/config.php` إلى Git أبداً.** لو تسرّب مفتاح، جدّده فوراً من
  لوحة المزوّد — الحذف من التاريخ لا يُبطل المفتاح.
- كل الاستعلامات تستخدم عبارات مُعدّة مع `PDO::ATTR_EMULATE_PREPARES => false`.
- كلمات المرور بـ `password_hash()`. الجلسات `HttpOnly` و `SameSite=Lax`
  و `Secure` على HTTPS، مع تجديد المُعرِّف عند الدخول.
- الصور المرفوعة تُفحص بـ `getimagesizefromstring()` ويُشتقّ امتدادها من النوع
  المُستشعَر لا من اسم الملف، وتنفيذ السكربتات محجوب داخل `uploads/`.
- سياسة `Content-Security-Policy` في `.htaccess` تسمح حالياً بـ `'unsafe-inline'`
  لأن السكربت والأنماط ومعالجات `onclick` مضمّنة في `index.html`. تشديدها
  يتطلّب أولاً إخراجها إلى ملفات منفصلة.

## الوصولية

المنصة موجّهة للأشخاص ذوي الإعاقة، فأي تعديل على الواجهة يجب أن يمرّ على:

- التنقّل بلوحة المفاتيح وحدها من أول عنصر إلى آخره
- قارئ شاشة واحد على الأقل (NVDA أو VoiceOver)
- التكبير حتى ٢٠٠٪ بلا فقدان محتوى
- وضع التباين العالي والوضع الداكن
